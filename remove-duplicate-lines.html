Remove Duplicate Lines Online - Free Dedupe Tool | TextKit

Clean a list by keeping only the first copy of each line. Useful for keyword lists, email lists, logs and any pasted list with repeats.

Your text stays in your browser. Nothing is uploaded or stored by this site.

How to use this tool

  1. Paste one item per line.
  2. Choose whether case and surrounding spaces matter.
  3. Press Remove duplicates and copy the clean list.

Example

Input apple, banana, apple, cherry gives apple, banana, cherry - the second “apple” is removed and order is preserved.

Frequently asked questions

Which copy is kept?

The first copy, in its original position. Later copies are removed.

Are “Apple” and “apple” duplicates?

Only if Ignore case is ticked. Otherwise they are treated as different lines.

Does it sort the list?

No. Use the Sort Lines tool if you also want alphabetical order.
